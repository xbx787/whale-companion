# Privacy Policy

Whale Companion (小鲸) runs on the user's own Windows machine. It does not
operate a project server and does not collect telemetry.

## What is stored locally

- Conversations, settings, memory files and attachments are stored in the
  application data directory on the user's computer.
- API keys are stored in the local settings store and are only used to call the
  model provider the user configured.

## What leaves the machine

- Messages and attachments are sent to the model provider selected by the user
  (for example DeepSeek) to generate replies.
- The update check requests the public GitHub releases feed for this repository.
  It sends no conversation content.
- No data is uploaded to the project maintainers.

## Third parties

Model providers process requests under their own privacy policies. The user
chooses which provider to configure.

## Contact

Questions or deletion requests can be opened at
