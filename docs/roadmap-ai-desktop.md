# 桌面智能体路线图（讨论稿）

本文件汇总主人与小鲸讨论过的方向，标明已完成与待做，作为后续开发的依据。

## 已完成

1. **提问卡**：对齐 Claudian 规格。胶囊 tab、答题绿勾、14px 单选/复选、下划线「其他…」、review 可点回改、主次按钮。数据走 `AskQuestionPanel`。
2. **审批卡**：拒绝 / 始终允许 / 允许一次。选「始终允许」后同类工具不再询问；实现于 `dsh-acp-agent` 的 `alwaysAllowedKinds`。
3. **计划审批（内核）**：补上 `setPlanListener` 与 `answerPlan`。ExitPlanMode 时把计划正文推给面板，`PlanApprovalPanel` 显示正文与批准/继续调整/放弃。
4. **计划审批中文化**：宿主的 Plan review 卡在渲染层翻译成中文，回答时映射回原 label。
5. **子代理**：对话内稿（timeline entry）与顶部状态卡并存；右键删除进会话级黑名单。
6. **跨重启状态**：`hiddenTabIds` 随 `library.json` 持久化。
7. **实例控制**：`second-instance` 无条件注册，`--quit` / `--restart` 可转发给运行中实例。
8. **WPS MCP（只读）**：`scripts/wps-com.ps1` 走 COM，`scripts/wps-mcp-server.cjs` 提供 `wps_list_documents`、`wps_read_document`、`wps_read_sheet`；冷启动 4.8 秒，超时放宽到 20 秒；真机验证过文字与表格。
9. **MCP 协议补全**：WPS server 声明 `resources`，三个工具带 `outputSchema`，文档以 `wps://document/<路径>` 暴露可读。
10. **全局急停**：`Control+Alt+Shift+Esc` 打断当前回合，退出时注销。
11. **审批细粒度**：设置里可列出「始终允许」的工具并单独撤销或清空。
12. **左侧刻度总数**：刻度改为从全量 timeline 生成，跳转时按全量分组定位并展开渲染窗口。
13. **右栏**：顶栏两个入口（面板开关、市场），三分区（目标 / 预览 / 市场）；目标可看条件、阶段、轮数，可继续、停止、改条件重发；预览只读、上限 200KB，点工具行路径直接送入；市场分应用 / 技能 / MCP，本地插件可一键安装。窄面板下并排自动退回覆盖。
14. **窗口透明度**：设置里 0 到 100 可调，0 视为关闭透明。

## 待做（按优先级）

1. **WPS 写入**：第二阶段，在只读基础上加改文字、写单元格，仍走审批。
2. **桌面操作（可见辅助）**：只做当前桌面上看得见、可随时打断的操作；不搞隐藏后台、不另起主机。
3. **插件安装真机验证**：`data/plugins` 放一个测试包，装完确认连接器进 MCP 库、技能可被读到。
4. **左栏图标入口**：左栏目前只有会话库，计划加市场、目标等入口。
5. **MCP 协议剩余**：prompts、list-changed。

## 已知缺口

- **会话切换被运行或压缩阻塞**：一个对话运行中、或压缩上下文时，不能切到另一个对话。疑似 DSH 会话串行模型，可能要大修。详见 `docs/2026-10-27-conversation-switch-blocker.md`。
- **命令执行被拆成两步**：工具超时后转后台 job，模型再轮询输出，需要估运行时间。应改为等进程退出即返回。详见 `docs/2026-10-27-command-execution-model.md`。
- **命令通道可绕过桌面控制授权**：`pwsh` 直接调 `user32` 就能模拟鼠标键盘，不经过 MCP 的权限门控。已在 MEMORY 写死规则，但代码层拦不住，需要宿主侧给命令执行加权限。
- **测试并行偶发超时**：`model-discovery`、`library-health` 已加 `closeAllConnections`，连跑两轮稳定；打包脚本仍无重试。

## 明确不做

- 跨端（手机远程、云电脑）。
- 企业托管与统一鉴权。
- Live2D 相关改动。

## 约束

- 打包只在最终 release 目录构建，绝不先打临时目录再移动。
- 重启只走 `evolve_restart` 或 `--restart`，不杀进程。
- UI 改动先在预览实例渲染确认，再做发布。

## 下一阶段计划

1. **渲染层内存**：面板目前把整段会话（含工具输出）留在渲染层，长会话稳定吃 3 到 4GB。计划三步：主进程按页下发最近 N 条并附总条数、工具输出入库前截断（完整内容留磁盘按需读）、折叠卡不保留展开状态。目标常驻降到几百 MB。
2. **发布流程脚本化**：打包、测试、冒烟、换版统一走 `scripts/release.ps1`，产出 `.tmp/release-result.json`；模型不再手拼命令。重启也做成一键脚本，先校验进程与快捷方式再切换。
3. **127 待验证**：状态点不再随窗口缩放上浮、顶栏整条可拖动、透明度滑块 100% 贴右且可调。
4. **Windows 工具**：`WinMcpClient` 懒启动已修，下个版本确认 `win_*` 能真正调用（保留原版与蓝色光晕，不重写）。
5. **插件与 WPS 真机验证**：本地插件安装后连接器是否进 MCP 库；WPS 写单元格后读回对比。
